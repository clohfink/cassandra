=======================================
This file records the changes specific to Netflix's internal fork of Apache Cassandra 4.1.
Upstream Apache Cassandra changes are tracked separately in CHANGES.txt.

Entries are grouped under the internal release tag in which they first shipped, newest first.
PR references (#NNN) point to pull requests in git.netflix.net/cde/nfcassandra.
